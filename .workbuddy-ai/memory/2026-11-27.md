# 2026-11-27

## Hugging Face Space 空页面翻译（iframe 正文兜底）

- 症状：`https://huggingface.co/spaces/dlouapre/looped-transformers` 点翻译提示
  `No translatable content`。顶层页只有 33 字符导航，全文（~38k 字符）在跨域 iframe
  `https://dlouapre-looped-transformers.hf.space/?__theme=system`。
- 根因：主 content script 没开 `all_frames`，且空页面兜底只会挖 PDF 源，不处理 HTML iframe。
- 修复：
  - `content.ts` 开 `allFrames: true`；子 frame 默认休眠，仅收到 `translatePage {frameFallback:true}` 才翻译。
  - 新增 `utils/embeddedFrame.ts` 的 `hasContentIframe()`：仅大尺寸、可见、非追踪器的 http(s) iframe 才触发。
  - `translation.ts` 顶层空内容时先试 PDF，再试 iframe 兜底；子 frame 空内容不报错。
  - `types/messages.ts` + `background.ts` 新增 `translateEmbeddedFrames`，background 广播到所有 frame（省略 frameId）。
  - `extractChatContext` / `findPdfSource` 仍只由顶层处理，避免子 frame 干扰。
- 验证：83 文件 / 786 用例通过；`vue-tsc --noEmit` 0 错误；Chrome / Firefox 构建通过，
  两个 manifest 的 content script 均为 `all_frames: true`。改动未提交。
