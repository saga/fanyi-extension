# 2026-10-28

## 阅读页白屏：`Cannot access 'contextGraphOverview' before initialization`（TDZ）

**根因**：上次 App.vue 拆分留下的循环依赖用「惰性 getter」绕过了类型层面的顺序问题，
但没绕过 JS 的 TDZ：

- `useLiteraryMemoryEditor()` 内部有个 `watch(() => deps.getContextGraphOverview() …)`，
  Vue 在 `doWatch()` 里会**立即执行一次 getter** 建立依赖；
- 而 `getContextGraphOverview: () => contextGraphOverview.value` 里的
  `contextGraphOverview` 是后面 `useContextGraph()` 解构出来的 `const`；
- setup 阶段编辑器先跑 → getter 命中未初始化 const → ReferenceError → 整个阅读页挂掉。

**修复**：把共享状态提到调用方，不再用 getter 延迟绑定。

- `useContextGraph.ts`：导出 `ContextGraphOverview` 类型 + `createEmptyContextGraphOverview()`；
  `ContextGraphDeps` 新增必填 `contextGraphOverview: Ref<ContextGraphOverview>`；
  内部不再 `const` 创建该 ref，改用传入的。
- `useLiteraryMemoryEditor.ts`：dep 从 `getContextGraphOverview()` 改为
  `contextGraphOverview: Ref<ContextGraphOverview>`，3 处调用点改 `.value`。
- `App.vue`：在两个 composable **之前** `const contextGraphOverview = ref(createEmptyContextGraphOverview())`，
  两边都传同一个 ref；不再从 `useContextGraph()` 解构它。

**顺带修掉两个被类型检查暴露的真 bug（同一子系统，均为既有问题）**：

1. `useLiteraryMemoryEditor` 的 return 漏了 `suppressedEntityCount` /
   `showSuppressedEntities` / `toggleSuppressedEntities` / `setStyleGuideAutoDisabled`，
   而 App.vue 解构并用于模板 → 运行时是 `undefined`。
2. `LiteraryBookMemory` 接口缺 `styleGuideOrigin` / `styleGuideAnalysisVersion` /
   `styleGuideSourceRevisionId` / `styleGuideAutoDisabled`（`sanitizeLiteraryMemory` 实际会返回，
   `LiteraryVoiceContext` 里也有同名定义）→ 类型与实现不一致。

**测试**：新增 `src/__tests__/documentReaderComposableWiring.test.ts`
- 按 App.vue 的真实顺序调用两个 composable（旧写法会 TDZ 抛错），并断言两边拿到同一个 ref；
- 源码级断言：`const contextGraphOverview = ref(` 必须出现在两个 composable 之前，
  且禁止出现 `getContextGraphOverview`（防止再退化成惰性 getter）。

**配置**：`vitest.config.ts` 补 `resolve.alias { '@': ./src }`，与 tsconfig `paths` 一致——
否则测试 import 生产模块时，模块内部的 `@/...` 无法解析。

**验证**：extension `vitest` 66 文件 / 610 通过；`wxt build` chrome+firefox 通过；
`vue-tsc` 在这 4 个文件上的错误从 **42 → 3**（剩余 3 条均为既有：`doc.value` 可能为 null、
`contextGraphState.status` 索引签名、`CharacterVoiceAnchor[]` 类型不匹配）；
构建产物中已无 `getContextGraphOverview`。
