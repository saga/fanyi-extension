## Claude cookbook 代码块大量 stale mapping 警告

- 症状：`platform.claude.com/cookbook/managed-agents-cma-dreaming-with-a-dynamic-workflow`
  服务端缓存回填时报 `block id mapping stale for b607/b612/b617...`，父代码行拿到子语法 span 的译文。
- 根因：hydrated DOM 里代码块与内部语法 span 都被抽成 block（嵌套 id）。服务端缓存 HTML 中
  父元素没有自己的 `.fanyi-translation`，只有子元素翻译。`applyServerTranslatedHtml` 和 PDF
  路径用 `el.querySelector('.fanyi-translation')` / `.fanyi-original`，会拿到**嵌套子块**的 span：
  父块误取 `“lead”` 当译文、`"lead"` 当原文 → 映射校验 false stale + 错误回填。
- 修复：`serverTranslation.ts` 新增 `directChildWithClass` / `getDirectTranslationText`，
  `getServerOriginalText` 只取直接子节点原文并剔除嵌套译文；两处回填路径都改用直接子 span。
- 测试：`serverCacheStaleMapping.test.ts` 新增 2 个回归用例（父无自身译文 / 父有自身译文）。
- 验证：84 文件 / 795 用例通过；`vue-tsc --noEmit` 0 错误；Chrome / Firefox 构建通过。
- 诊断数据：当前静态 HTML 抽 311 块，hydrated DOM 抽 705 块；服务端 `/check` 不带 contentHash
  可返回 1.19MB 旧缓存，带当前指纹返回 410。改动未提交。
