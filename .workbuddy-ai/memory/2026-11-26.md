# 2026-11-26

## protocolis.co/paper 落地页点翻译无反应

- 现象：在 https://protocolis.co/paper/ 点扩展翻译，PDF 没有反应。
- 根因：该页用脚本只在宽屏 + hover 环境注入 `<object type="application/pdf">`；窄屏/触屏下只剩
  普通 `<a href="*.pdf">Read the paper</a>` / `Download PDF` 链接。`findPdfSource` 只查
  self / iframe / embed / object，不查链接，于是走普通网页翻译。
- 修复：`src/entrypoints/utils/pdfSource.ts` 增加保守的 PDF 链接兜底检测：同 URL 至少 2 个
  「Read/Open/Download ... paper/PDF」链接，或 `/paper/` 落地页上的单个主链接，才识别为 PDF 源；
  普通文章里附带一个 PDF 链接不会误触发。`via` 新增 `'link'`。
- 测试：`pdfSource.test.ts` 新增 3 例；全量 73 文件 / 715 用例通过；`vue-tsc` 0 错误；
  Chrome/Firefox 构建通过。
