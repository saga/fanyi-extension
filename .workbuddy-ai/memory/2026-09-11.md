## 修复：Firefox Android 对话发送按钮溢出屏幕

**现象**：Firefox 移动端，「对话」输入区的发送按钮布局超出屏幕。

**定位**：对话 UI 在 `src/entrypoints/sidepanel/App.vue`（入口 `sidepanel.html`）。
Firefox Android 不支持侧栏（`isSidebarSupported()` 返回 false），对话以**普通标签页**打开。
输入区 `.composer` 是三列 flex：`[JSON 44px] + [textarea flex:1] + [发送 min-w 56px]`，`gap:8px` + `padding:8px 10px`。

**根因**：经典 flexbox **min-content 下限**。flex 项默认 `min-width:auto` = min-content，
而 `<textarea>` 的 min-content ≈ `cols` 默认值（20 字符）。桌面侧栏够宽能吸收，
手机视口（~360–412px）下 textarea 下限 + 两个固定按钮 + gap 超过视口宽度 → 发送按钮被挤出屏幕。

**修复**（仅改 `sidepanel/App.vue` 样式，不动逻辑）：
1. `.input` 加 `min-width: 0;` —— 真正治本，让 textarea 能收缩到下限以下。
2. `.composer` 加 `flex-wrap: wrap;` —— 兜底，任何极端窄屏都不会越界（按钮换行而非溢出）。
3. `@media (max-width:480px)` 内压缩固定控件：JSON `min-w 38/高 40`、发送 `min-w 48/高 40`、input padding 略减，
   尽量让「输入框 + 发送」保持同一行，发送按钮保留可用点击尺寸。

**验证**：`wxt build --mode chrome` + `--mode firefox` 均干净通过（sidepanel CSS 6.17→7.23 kB）；
已确认三条规则都进入构建产物 `output/chrome-mv3-*/assets/sidepanel-*.css`（`.input` 的 `min-width:0`、
`.composer` 的 `flex-wrap:wrap`、`max-width:480px` 块内的压缩规则）。
