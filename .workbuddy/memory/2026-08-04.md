# 2026-08-04

## 修复：MIT Sloan 页面点击翻译后白屏

**现象**：访问 https://mitsloan.mit.edu/ideas-made-to-matter/... 点击翻译，整页立即变白。
console 最后一条日志是 `initiatePullPoptinsRequest()`。

**根因**：MIT Sloan 集成了 Poptins（poptins.com，营销弹窗工具）。Poptins 通过外部
CDN 脚本**运行时动态注入**全屏白色弹层，且恰好在点击翻译、正文翻译进行中才触发
（`initiatePullPoptinsRequest` 是注入入口）。扩展的 `hideBodyOverlays()` 只在翻译开始
时**同步跑一次**，此时弹层还不存在，所以没被捕获；动态注入的弹层既没被一次性隐藏，
也不在 `styles.ts` 的 `[class*="notification"]` 规则范围内（其 class 是 `poptin-*`
而非 `notification`），于是盖住整页 = 白屏。

**排除项**：`academics-overlay` 是独立 nav 浮层（不在 `<main id="main-content">` 内），
`hideBodyOverlays` 隐藏它是正确的，不是误伤正文；正文根 `<main role="main">` 识别正常。

**修复**（3 个文件 + 1 个测试）：
- `src/entrypoints/utils/blockExtractor/rules.ts`：`OVERLAY_PATTERNS` 增加 poptin
  识别（class/id 含 `poptin`，及 iframe src 含 `popt.in`）。
- `src/entrypoints/utils/contentHelper.ts`：`hideBodyOverlays` 候选选择器增加
  `[class*="poptin"]`/`[id*="poptin"]`/`iframe[src*="popt.in"]`；新增
  `createOverlayHider()`——翻译期间用 MutationObserver 持续隐藏"翻译开始后才注入"
  的动态弹层，先用廉价 CSS 候选选择器收窄再调 `isOverlayElement`，并跳过扩展自身
  UI（class 以 `fanyi-` 开头），不监听 attributes/characterData 避免性能与循环问题。
- `src/entrypoints/content/translation.ts`：`handleFullTranslation` 在 `prepareDocument`
  之后启动 overlayHider；控制器 `restore()` 时停止它。
- `src/__tests__/overlayHider.test.ts`：5 个用例验证 poptin/overlay 动态注入被隐藏、
  扩展 UI 与正文内 poptin 不被误隐藏、stop 后失效。

**注意**：`pnpm compile`(vue-tsc) 在本环境报大量**预存**错误（缺 WXT 生成全局类型
`defineContentScript`/`browser`、Vue 宏、compromise 类型、storage key 类型等），
与本次改动无关；本次改动的 3 个文件类型检查无报错。
