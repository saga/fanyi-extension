# 2026-09-09

## archive.md 翻译遗漏修复
- **页面**：`archive.md/PfnMf`（New Yorker 文章《The Paperboy's Secret》镜像）
- **现象**：用户报告"翻译明显有问题，有内容没翻译"
- **根因**：archive.md 全部内联样式（无 class 属性），walker 的 `classifyNode()` 基于 class 的噪声检测完全失效。238 个提取块中 ~40-50% 是噪声（音频播放器控件 16 块、视频嵌入 3 块、卡通工具栏 3 块等），稀释翻译质量。
- **修复**：在 `contentHelper.ts` 新增 `filterNoiseBlocks()` 后处理过滤器，基于文本正则匹配移除 UI/媒体播放器/工具栏块（22 个模式）。保守策略，只移除明确命中的噪声块。
- **效果**：238 → 216 块（移除 22 噪声块），923 测试全过。fixture 存 `src/__tests__/fixtures/archive-md-article.html`。
- **vocal-saga**：此修复是 fanyi-extension 侧通用后处理，vocal-saga 的 linkedom 提取管线独立，暂不需同步（若 vocal-saga 也遇到同类问题再加）。
