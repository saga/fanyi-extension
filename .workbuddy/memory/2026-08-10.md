# 2026-08-10

## Netflix Tech Blog 翻译文字重叠根因与修复
**现象**：netflixtechblog.com 页面翻译后，中文译文显示在英文原文上方（重叠），而非正确的上下排列。

**根因（双路径问题）**：
1. **扩展端 CSS 被站点覆盖**：`styles.ts` 中 `.fanyi-original/.fanyi-translation` 仅用简单 class 选择器设 `display: block`，
   无 `!important`，Medium 等站点的全局 span 规则或 flex/grid 布局可覆盖导致重叠。
2. **服务端 `/force/` 路径完全不注入翻译 CSS**：`processTranslationHtml` pipeline 只有
   stripDangerousScripts → devirtualizeLayout → injectRedirectGuard，无 CSS 注入步骤。
   浏览器直访 `/force/` 时 `.fanyi-original/.fanyi-translation` 是裸 `<span>`（inline），定位完全由站点决定。

**修复**：
- **fanyi-extension `styles.ts`**：`.fanyi-original` 和 `.fanyi-translation` 加 `!important` + 防御性样式
  （position:static, float:none, clear:both, order:0/1）防止站点覆盖和 flex 反转。
- **vocal-saga `lib/app.ts`**：新增模块级 `injectTranslationCss(html)` + `TRANSLATION_CSS` 常量，
  插入 `processTranslationHtml` pipeline（strip → devirtualize → **injectCss** → redirectGuard）。
  智能注入点：`</head>` 前 > `<head>` 内 > `<body>` 后 > `<html>` 后 > 前缀兜底。
- 新增测试：`injectTranslationCss` 单测 ×6（覆盖各种 HTML 结构 + CSS 内容校验）。
- 全量测试：fanyi-extension 865 passed，vocal-saga **1123 passed**（+6）。
- 扩展已 rebuild，vocal-saga 已部署 CF Workers 版本 `54eac8df`。
