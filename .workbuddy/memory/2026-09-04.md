# 2026-09-04

## 新增「网页对话」tab 功能（fanyi-extension）
在翻译插件里加了一个独立浏览器 tab，注入当前页正文作为上下文做多轮对话。

### 关键文件
- `src/entrypoints/chat/`：tab 页（index.html + main.ts + App.vue）。移动优先布局：viewport-fit=cover、100dvh、safe-area insets、底部输入栏、流式气泡。
- `src/entrypoints/service/chat.ts`：`chatStream`（SSE 流式）/ `chat` / `buildChatSystem(context)`。复用 DeepSeek `deepseek-v4-flash`，system prompt 注入网页 title/url/正文。
- `src/entrypoints/background.ts`：
  - `getActiveContentTabId()` —— Firefox Mobile 安全：用 `tabs.onActivated`/`onUpdated` 记录「最后一个非 chat.html 的内容标签页」（`lastContentTabId`），回退 `tabs.query({active:true})`（不依赖 `currentWindow`，后者 Android 无效）。
  - `getPageContext` 消息：向目标 content script 发 `extractChatContext` 取上下文。
  - `runtime.onConnect({name:'chat'})` 端口：流式回传 `{type:'partial'|'done'|'error'}`。
- `src/entrypoints/content.ts`：新增 `extractChatContext` case，调用 `prepareDocument(document)` 取正文（失败退化为 `body.innerText`），截断 16000 字。
- `src/types/messages.ts`：新增 `ExtractChatContextMessage` / `GetPageContextMessage` / `PageContext` / `GetPageContextResponse`。
- `src/entrypoints/popup/App.vue` + `background.ts`：新增「对话」按钮（popup）与「用本页内容对话」右键菜单（带 `?sourceTabId=N` 开 chat tab）。

### 设计要点
- 移动端触发：右键菜单（Android Firefox 支持 contextMenus）+ `lastContentTabId` 兜底（直接打开 chat.html 也能聊刚看的页）。
- 对话走 background 调 DeepSeek（需用户填 API Key），复用现有 `https://api.deepseek.com/*` 权限，无需新 host 权限。
- 893 测试全过；`wxt build -b firefox` 产出 `chat.html`（573B + 独立 chunk）。
